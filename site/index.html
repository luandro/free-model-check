Audit Rules & Definitions

Understanding Free-ness Labels & Scores

Every route is audited against live provider pricing structures using exact arbitrary-precision Decimal parsing so tiny non-zero floats (such as 1e-999) never underflow to zero.

zero-priced Included by default

Verified Zero-Priced Route

The provider publishes an explicit 0 price across all required token fields and every remaining billable dimension in the pricing tree: input/output tokens, requests, images, audio, cache read/write, and context tier overrides. OpenRouter routes must also declare text-only output modalities and contain no price mentions in their prose description.

Provider marker: provider (no suffix symbol)
free-tier (*) Opt-in (--include-free-tier)

Unverified Free-Tier Claim

Asserted by the F24 SALES LiteLLM scanner while pointing at a vendor endpoint that requires your own provider API key (requires_provider_key: true). Usage is subject to account quotas and may bill at standard list price without warning.

Provider marker: provider* (asterisk suffix)
mirror-listed (†) Opt-in (--include-free-tier)

Stale Third-Party Mirror

A third-party capability mirror (models.dev) lists zero cost (stale_mirror: true), but the live upstream provider catalogue does not confirm a free route. Excluded by default so lagging mirror state never pollutes the verified shortlist.

Provider marker: provider† (dagger suffix)
StealthMark proxy Separate proxy section

StealthMark General Proxy Score

Evaluates newly released or stealth models absent from Artificial Analysis using StealthMark's General score (0–100) from complete 8-scene runs. StealthMark tests visual-SVG generation and multi-step planning games rather than software engineering; it is labelled stealthmark-proxy and never overrides an Artificial Analysis score.

Score source: stealthmark-proxy

Score Sources: own vs inherited

Artificial Analysis's free API tier exposes artificial_analysis_intelligence_index (coding and agentic sub-indices are Pro-only). When a canonical AA model slug has no direct score while a dated snapshot or reasoning variant in the same model family is scored, the pipeline inherits the family's highest score and marks score_source: "inherited" alongside the exact donor slug in score_inherited_from.

Agent Readiness Gate

Each model is cross-referenced against models.dev capability metadata. A model is marked Agent Ready when tool_call is confirmed true and its context window meets or exceeds 65,536 tokens (64K).
